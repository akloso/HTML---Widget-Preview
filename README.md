# HTML & Widget Preview | Zapora

A polished, static GitHub Pages tool for previewing HTML, iframe, form, button, and JavaScript widget snippets in a fresh browser tab.

## Purpose

HTML & Widget Preview helps users paste third-party widget or embed code and open it as a complete preview document without rendering the code inside the tool page. It is designed for quick checks of marketing forms, iframes, buttons, script widgets, and hand-written HTML/CSS/JavaScript snippets.

## Supported modes

- Combined Code
- DIV + Script
- Button + Script
- Iframe Only
- HTML + CSS + JavaScript

## File structure

- `index.html` — semantic page structure, metadata, mode controls, editor container, actions, and status area
- `styles.css` — responsive Zapora-style visual design, accessible focus states, and mobile-safe layout
- `script.js` — input state, mode switching, preview document generation, copy, clear, and reset behavior
- `README.md` — project overview and usage notes

## Technology

This project intentionally uses only plain HTML, CSS, and JavaScript.

- No dependencies
- No package manager setup
- No React, Vite, Tailwind, Bootstrap, or external UI libraries
- No backend, analytics, cookies, localStorage, or sessionStorage
